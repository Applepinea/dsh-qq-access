# 验证说明

版本：1.1.4514

## 当前状态

这个插件是在真实环境里开发和调试出来的：真实的 QQ 号、真实的 NapCat、
真实的群聊与私聊、真实的 QQ 空间。功能层面的行为都有实测依据。

测试分两层：`npm test` 跑 `tests/smoke.test.mjs` 的冒烟测试（不需要 DSH 宿主），
`npm run check` 跑清单与语法自检。**没有行为测试**——回复质量、情感演进、
记忆召回这些需要真实 QQ 环境，冒烟测试覆盖不到。

## 已验证的机制

以下机制在开发过程中有明确的实测记录，写在这里是为了让使用者知道哪些行为
是被验证过的，而不是照着文档猜。

### 消息与回复

| 项目 | 验证方式 | 结论 |
| --- | --- | --- |
| 自动回复 | 真实私聊 | 正常，含分段发送 |
| 群聊 @ 回复 | 真实群聊 | 正常，@ 会转成真实蓝色提及 |
| 引用上下文 | 真实引用消息 | 能还原被引用内容 |
| 图片收发 | 真实图片 | 模型能看到收到的图，能发本地图 |
| 撤回 | 真实发送后撤回 | 2 分钟内有效 |

### QQ 空间

| 项目 | 验证方式 | 结论 |
| --- | --- | --- |
| 读说说 | 真实空间 | 能读到内容、时间、图片、评论 |
| 发说说 | 真实发布 | 发布后读回列表确认 |
| 评论 | 真实评论 | 早期用浏览器时评论会落到错误的说说上，改成 HTTP 后定位正确 |
| 删除 | 真实删除 | 需要 `feedsKey` / `feedsAppid` / `feedsTime`，缺一个就返回 `-3` |
| 定时发动态 | 真实运行 | 时间槽按日期哈希，同日重启不变 |

### 情感与关系

用真实 `EmotionStore` 做过单元级验证：

- 8 维情感、四阶段门槛、滞后带上下边界
- 负好感三档区制（亲密权重归零）
- 单轮变化钳制（好感 ±5、情感 ±3）
- 亲密度增益在过渡期生效、负向不放大
- 10 轮并发写入不丢数据
- 持久化后重载一致

### 群聊判断

- 被 @ / 被引用 / 被叫名字 三种无条件触发
- QQ 号的边界匹配（`11234567890` 不会误判成 `1234567890` 这样的前缀/后缀）
- 6 类兴趣词、3 类对人说话、3 类群体提问
- 8 条闲聊短句全部跳过
- 阈值上下边界

### 长期记忆

- 衰减：半衰期 30 天时，30 天前鲜活度恰为 0.5，一年后接近 0
- 证据门槛：相关查询有分，无关查询（「股票」）为 0，具体词（「布偶猫」）分数高于单字（「猫」）
- 单字召回：「猫」能召回「她养了一只布偶猫」
- 事实常驻：无关查询下事件为 0 但事实仍注入
- 事实键：同一键写两次，旧的标 superseded，召回只返回新的
- 每日配额：配额设 2 时连写 5 条只落 2 条
- 并发：10 条同时写入不丢
- 持久化：重载后条数一致
- 跨场景：群里说的「养了布偶猫」，私聊问起能召回；私聊说的「下周三出差」，群里也能召回

### 时间上下文

- 秒 / 毫秒 / Date / ISO 四种格式解析一致
- 12 档相对时间（刚刚 / 5 分钟前 / 3 小时前 / 昨天 / 4 天前 / 2 周前 / 3 个月前）
- 间隔描述是时长而非时点
- 2 小时阈值的长间隔提示

## 已知限制

- **归档保留期**：默认 30 天，可设为 `0` 永久保存。超过保留期的历史查不到。
- **QQ 历史接口**：NapCat 的历史可能不完整，翻页有上限。
- **cookie 时效**：QQ 空间 cookie 会过期，插件会自动重新取；取不到时需要重新登录 QQ。
- **群聊判断**：是启发式的，不是模型判断。偶尔会漏掉该回的消息，或者回了不该回的。
  阈值和兴趣词都可以在面板里调。
- **情感分析**：默认调用一次额外模型。关掉后退回关键词分析，省钱但更粗糙。

## 如何自己验证

```powershell
# 只读自检：连接、NapCat、空间 cookie
node cli.mjs doctor
```

仓库目前还没配 CI。提交前请手动跑这两条命令：

```bash
npm run check    # 清单字段、文件完整性、语法、客户端 bundle 约定、工具清单一致性
npm test         # 冒烟测试
```

`check` 里包含这几项：

1. 所有 `.mjs` / `.js` 的 `node --check`
2. 客户端 bundle 里 `require()` 的宿主模块是否都在 `dsh.client.external` 里声明
3. 工具清单、白名单、能力指南三者是否一致

第 2 和第 3 项是因为这个项目实际出过这类问题：语法检查通过但运行时报错，
`external` 漏声明导致面板白屏，以及新增工具后忘了同步白名单导致模型看不到那个工具。
